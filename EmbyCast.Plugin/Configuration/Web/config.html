Announce a countdown (e.g. before a restart) with reminders sent at chosen minute marks. The session list is re-checked before every reminder, so users who log in mid-countdown still get the remaining reminders.

Welcome Message

Automatically sent the first time a user ever logs in.

The first time you enable this, every existing user gets the message at their next login. After that, only users logging in for the very first time receive it - editing the text or toggling it off and on again does not resend it to anyone already welcomed.
